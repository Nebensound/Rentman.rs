
## Resource names and API collections

Rust names describe singular resources; request schemas become `Payload` types.
Names are normalized to resource-focused English where the API uses another
language or inconsistent singular/plural forms. In particular,
`CrewRateResponse` is `Rate` (`/rates`), whereas `CrewRatesResponse` is
`CrewRate` (`/crewrates`): these are distinct resources.

The complete mapping below is generated from the same contract as the models.
A request schema listed here identifies its payload type, not a promise that
every collection supports every write operation.
